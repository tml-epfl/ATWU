# TOFU sensitivity and scorer-transfer ablations

This branch isolates the following additions to the reproducible TOFU pipeline
on `main`:

1. one-dimensional sensitivity sweeps for the population budget `rho` and the
   saturation parameter `beta`;
2. five frozen-scorer fold controls;
3. five-fold scorer transfer under two holdout schemes: unseen authors and
   unseen facts/questions (ten leave-one-fold-out runs).

All runs use TOFU forget10, Llama-3.2-1B-Instruct, and the selected ATWU
hyperparameters from `scripts/selected_tofu.json`.

For a clean rerun, point the drivers at a fresh state directory:

```bash
export ATWU_SWEEP_ROOT=saves/sweep_atwu-rerun
```

## Rho and beta sensitivity

The grid contains 20 distinct configurations: `rho` in 0.1–1.0 and `beta` in
0–10, sharing the reference point `(rho=0.2, beta=7)`.

```bash
# Inspect the exact manifest without launching training.
python scripts/sweep_atwu_sensitivity.py --list

# Generate the untouched retain90 reference used by the plots.
python scripts/sweep_atwu_sensitivity.py --reference-model --gpu 0

# Run 20 sensitivity and 5 frozen-scorer-fold jobs across five GPUs.
bash scripts/sweep_atwu_launch.sh

# Or run one resumable shard.
python scripts/sweep_atwu_sensitivity.py --shard 0 --num-shards 5 --gpu 0

# Collect results and regenerate both figures.
python scripts/sweep_atwu_sensitivity.py --collect
pip install matplotlib
python scripts/plot_atwu_sensitivity.py
```

Generated records and figures are written under `$ATWU_SWEEP_ROOT` and remain
ignored by Git. Compact reference results are checked in under `results/`.
The five frozen-scorer controls launched here are separate from the author/fact
holdout runs below.

## Five-fold scorer transfer

First verify the assumed TOFU ordering and fold membership:

```bash
python scripts/check_tofu_folds.py
```

Run both leave-one-fold-out schemes. Scheme `author` withholds four complete
authors per fold; scheme `question` withholds four QA rows from every author.

```bash
# Untouched-model control needed by the fold analysis.
python scripts/sweep_atwu_sensitivity.py \
  --reference-model open-unlearning/tofu_Llama-3.2-1B-Instruct_full \
  --kfold both --gpu 0

for shard in 0 1 2 3 4; do
  python scripts/sweep_atwu_sensitivity.py \
    --kfold both --shard "$shard" --num-shards 5 --gpu "$shard" &
done
wait
```

Recompute the end-to-end fold AUROC and token-level scorer AUROC:

```bash
python scripts/kfold_auroc.py \
  --baseline "$ATWU_SWEEP_ROOT/reference_model/tofu_Llama-3.2-1B-Instruct_full/TOFU_EVAL.json"

# Reference/frozen-fold scorer analysis used by the compact export.
python scripts/scorer_auroc.py \
  --labels data/gpt-selected-tokens-tofu/forget10_with_common_words_gpt \
  --out "$ATWU_SWEEP_ROOT/scorer_auroc.json"

python scripts/scorer_auroc.py --kfold \
  --labels data/gpt-selected-tokens-tofu/forget10_with_common_words_gpt \
  --out "$ATWU_SWEEP_ROOT/scorer_auroc_kfold.json"

# Include the completed holdout records in summary.json.
python scripts/sweep_atwu_sensitivity.py --collect
```

The analysis commands consume the scorer checkpoints and per-example fold
evaluations generated by the runs above. Checkpoints, evaluation dumps, trainer
states, plots, and individual records remain under the ignored sweep root.

After collecting both ablations, regenerate the compact reference results:

```bash
python scripts/export_tofu_ablation_results.py \
  --root "$ATWU_SWEEP_ROOT" \
  --output-json results/tofu_ablations.json \
  --output-md results/tofu_ablations.md
```

The JSON retains every sensitivity point, selected hyperparameters, reference
model metrics, per-fold author/fact transfer results, aggregate statistics, and
end-to-end fold metrics. The Markdown file contains the corresponding concise
tables and conclusions.

Set `ATWU_PYTHON`, `HF_HOME`, or the normal Hugging Face environment variables
when non-default interpreter/cache locations are required; no machine-specific
path is assumed.
